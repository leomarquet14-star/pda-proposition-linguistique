# PDA — Peur Des Abréviations

**Proposition terminologique de Léo Marquet (2026)**

Le sigle **PDA** est proposé pour désigner la peur des abréviations. Il présente une particularité linguistique : son nom est lui-même une abréviation.

La publication propose également les notations **PDA², PDA³ et PDAⁿ**, ainsi qu'une démonstration par récurrence établissant que cette règle de dénomination peut être prolongée sans borne.

Il s'agit d'une **proposition terminologique** et non de la reconnaissance d'un trouble médical.
